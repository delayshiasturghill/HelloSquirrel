AND101 Project 1 - Hello, Squirrel!

Submitted by: Delayshia Sturghill

Time spent: 2 hours spent in total

Summary
Hello, Squirrel! is an Android application that introduces me through a personalized profile. I updated the app to display my name, a short biography, and my three favorite hobbies.
My profile explains that I am an Information Systems student at Kennesaw State University who enjoys helping others, learning new things, and exploring business and technology. My goal is to build a successful career and eventually own my own business.
If I had to describe this project in three (3) emojis, they would be: 👩🏽‍💻 🎂 🌿
Application Features

The following REQUIRED features are completed:
	☑	Change profile name to your name
	☑	Change profile bio text to a personal bio about yourself
	☑	Modify hobby section to include your top three (3) hobbies
  
The following STRETCH features are implemented:
	☐	Re-brand the app by modifying the UI
	☐	Modify profile image by uploading a new image drawable
The following EXTRA features are implemented:
	☐	No additional features implemented

Notes
Throughout this project, I learned how to use Android Studio to customize an existing Android application. I gained experience editing the strings.xml file, updating text displayed in the application, and running the app using an Android emulator.
I also practiced using Git and GitHub to commit my changes and upload my project. This assignment helped me become more comfortable navigating Android Studio and understanding how application resources are used.
